02 / METHODOLOGY

하나의 ‘검증 완료’로
묶지 않는 세 가지 질문

거래 일치, 장부 정합성, 전략의 유용성은
서로 다른 증거가 필요합니다.

Q.01

시장 기록과 일치하는가?

공통 식별자와 종목·시각·가격·수량을 대조합니다. 일치해도 계정 소유나 파일의 완전성까지 증명하지는 못합니다.

필요한 증거 / 키·단위·커버리지
Q.02

돈의 흐름이 설명되는가?

입출금, 계약별 손익, 수수료, 펀딩을 잔액과 연결합니다. 이익 거래의 합계만으로는 장부를 설명할 수 없습니다.

필요한 증거 / 잔액 대사·차이의 원인
Q.03

다른 기간에도 유용한가?

당시 알 수 있었던 정보로 가설을 세우고, 독립 구간에서 비용과 같은 위험을 반영해 비교합니다. 유용한 가설이 없을 수도 있습니다.

필요한 증거 / 시간 분리·순증 효과

증거가 쌓여야 열리는 연구 게이트

G0 — G6 / 개념적 절차

아래는 통과 이력이 아닌 연구 설계입니다. 지금은 출처 단계에서 멈춰 있으며, 뒤 단계가 자동으로 승인되지는 않습니다.

  1. G0

    출처 확보

    원문·파일·해시·공개 경로·사용 범위를 기록합니다. 미충족 시 실제 데이터 학습을 시작하지 않습니다.

    BLOCKED_SOURCE
  2. G1

    스키마·장부

    단위·시각·계약을 확정하고 중요한 미설명 잔액 차이를 해소합니다.

    대기
  3. G2

    공개 체결 일치

    공통 키, 대조 결과와 자료 공백을 보고합니다. 제한된 대조를 진위 인증으로 부르지 않습니다.

    대기
  4. G3

    시간·실행 가능성

    정보의 관측 시점, 거래 가능 가격, 수수료·슬리피지·펀딩을 검증합니다.

    대기
  5. G4

    독립 연구 검증

    가설 사전 등록, 독립 구간, 순증 효과와 위험을 평가합니다. 기각·근거 부족도 결과입니다.

    대기
  6. G5

    Shadow · 가상 운용

    주문을 전송하지 않고 실시간 의도·상태·비용·장애 처리를 확인하는 후속 연구 단계입니다.

    비활성
  7. G6

    Canary · 별도 승인

    사람의 승인, 자금·위험 한도, 롤백 준비가 없으면 실거래 금지입니다. 이 사이트는 실거래를 지원하지 않습니다.

    비활성
연구 대상으로 제안한 후보 모듈발견된 실제 전략 아님

아래 후보는 기존 봇에 대한 비교 실험의 출발점일 뿐, 워뇨띠의 실제 전략을 복원하거나 성능을 확인한 결과가 아닙니다. 모두 PROPOSED입니다.

P1 · PROPOSED

RegimeEntryFilter

기존 진입 신호에서 부적합한 시장 환경을 거르는 필터. 같은 위험에서 비용 후 성과가 개선되는지 묻습니다.

P1 · PROPOSED

ExposureScalingPolicy

변동성과 보유 재고를 반영하는 제한적 노출 조절. 손실·집중 위험을 함께 비교합니다.

P2 · PROPOSED

PartialExitPolicy

부분·시간·추적 청산의 순증 효과를 독립 시험합니다. 청산만 바꾼 기준선과 비교합니다.

P2 · PROPOSED

LossCooldownFilter

확정 손실 뒤 신규 위험 증가를 잠시 제한하는 후보. 기회비용과 낙폭을 함께 살펴봅니다.

03 / DATA READINESS

분석의 시작은
데이터를 확인하는 일

파일이 크다는 사실과
연구에 쓸 수 있다는 판단은 다릅니다.

원본 준비 체크리스트

모두 확인 대기

  • 원문과 권한

    게시 URL·게시 시각·공개자·사용 범위. 공개 자료라도 재배포·학습 권한을 가정하지 않습니다.

  • 거래·지갑 파일 전체

    설명서와 모든 시트·압축 항목을 조사하고 원본 바이트를 보존합니다.

  • 파일 동일성 기록

    출처 URL·수집 시각·바이트·SHA-256을 기록합니다. 해시는 작성자 진위 인증이 아닙니다.

  • 스키마와 대조 가능성

    열·통화·부호·시간대·계약과 공통 키를 확인합니다. 누락·중복·대조 불가 범위를 보존합니다.

05 / QUESTIONS & BOUNDARIES

자주 묻는 질문

연구가 말할 수 있는 것과
아직 말할 수 없는 것.

워뇨띠가 운영하는 공식 사이트인가요?

아닙니다. 이 사이트는 비공식 독립 연구 프로젝트입니다. 트레이더 워뇨띠나 BitMEX가 운영·보증·승인하지 않았으며, 계정 소유자와의 관계나 자료의 진위를 인증하지 않습니다.

실제 분석 결과나 백테스트를 볼 수 있나요?

아직 없습니다. 원문과 거래·지갑 파일을 확보하지 못해 검증과 백테스트는 NOT_RUN입니다. 첫 산출물은 수익률 차트가 아니라 데이터 감사 보고서와 장부 대사 보고서여야 합니다.

공개 체결이 일치하면 수익률도 검증되나요?

아닙니다. 시장 기록과 일치한다는 사실은 계정 소유, 전체 거래의 누락 여부, 입출금·수수료·펀딩을 포함한 수익률을 입증하지 않습니다. 출처·거래 일치·장부·전략의 유용성은 분리해 보고합니다.

제안된 모듈은 실제 전략을 복원한 것인가요?

아닙니다. 모두 PROPOSED인 비교 실험 후보입니다. 독립 구간과 현실적인 비용을 반영한 검증 전에는 전략으로 승격하지 않습니다. 유용한 가설이 발견되지 않거나 근거가 부족한 결과도 정상적인 연구 결과입니다.

로그인, 파일 업로드, 자동매매 기능이 있나요?

없습니다. 이 사이트는 정적 연구 노트이며 계정 연결·파일 수집·시장 데이터 조회·주문 전송을 하지 않습니다. 분석용 추적 도구도 사용하지 않습니다. 참고 자료 링크를 선택하면 외부 사이트로 이동합니다. 향후 운용 연구 역시 별도 승인과 위험 검증이 필요합니다.
