DISCLOSURE PURPOSE

공개 취지와 이용 범위

과거 거래·성과 검증과 사람이 읽고 참고하는 관측에 한정합니다. 거래내역을 자동매매 알고리즘 학습·무단 봇 제작·배포·판매에 사용하지 않습니다.

체결 기록만으로 진입 보류, 취소·변경 이유와 당시 판단을 복원할 수 없습니다. 닉네임을 내세운 봇을 구매하거나 맹신하지 말라는 공지의 경고를 함께 전합니다.

사용자가 제공한 공지의 취지를 요약했습니다. 원문 URL·게시 시각은 미확인으로, 당사자 확인이나 법적 권리 판단을 대신하지 않습니다.

02 / METHODOLOGY

하나의 ‘검증 완료’로
묶지 않는 세 가지 질문

시장 기록, 자금 흐름, 해석의 한계를
각각 구분해 확인합니다.

Q.01

시장 기록과 일치하는가?

공통 식별자와 종목·시각·가격·수량을 대조합니다. 일치해도 계정 소유나 파일의 완전성까지 증명하지는 못합니다.

필요한 증거 / 키·단위·커버리지
Q.02

돈의 흐름이 설명되는가?

입출금, 계약별 손익, 수수료, 펀딩을 잔액과 연결합니다. 이익 거래의 합계만으로는 장부를 설명할 수 없습니다.

필요한 증거 / 잔액 대사·차이의 원인
Q.03

기록만으로 알 수 없는 것은?

진입 보류, 미체결·취소 주문과 판단 이유는 체결 기록만으로 알 수 없습니다. 관측한 결과와 사람의 의도에 대한 추측을 구분합니다.

모두 확인 대기

  • 원문과 권한

    게시 URL·게시 시각·공개자·사용 범위. 공개 자료라도 재배포·학습 권한을 가정하지 않습니다.

  • 거래·지갑 파일 전체

    설명서와 모든 시트·압축 항목을 조사하고 원본 바이트를 보존합니다.

  • 파일 동일성 기록

    출처 URL·수집 시각·바이트·SHA-256을 기록합니다. 해시는 작성자 진위 인증이 아닙니다.

  • 스키마와 대조 가능성

    열·통화·부호·시간대·계약과 공통 키를 확인합니다. 누락·중복·대조 불가 범위를 보존합니다.

05 / QUESTIONS & BOUNDARIES

자주 묻는 질문

연구가 말할 수 있는 것과
아직 말할 수 없는 것.

워뇨띠가 운영하는 공식 사이트인가요?

아닙니다. 이 사이트는 비공식 독립 연구 프로젝트입니다. 트레이더 워뇨띠나 BitMEX가 운영·보증·승인하지 않았으며, 계정 소유자와의 관계나 자료의 진위를 인증하지 않습니다.

실제 거래 검증 결과를 볼 수 있나요?

아직 없습니다. 원문과 거래·지갑 파일을 확보하지 못해 검증은 NOT_RUN입니다. 첫 산출물은 데이터 감사 보고서와 장부 대사 보고서이며, 실제 결과가 없으면 미실행으로 남깁니다.

공개 체결이 일치하면 수익률도 검증되나요?

아닙니다. 시장 기록과 일치한다는 사실은 계정 소유, 전체 거래의 누락 여부, 입출금·수수료·펀딩을 포함한 수익률을 입증하지 않습니다. 출처·거래 일치·장부·해석의 한계를 분리해 보고합니다.

거래내역으로 당시 판단을 알 수 있나요?

체결 기록은 실행된 결과이지 판단 전체가 아닙니다. 진입 보류, 취소·변경 이유, 미체결 주문과 화면 밖의 상황은 알 수 없습니다. 관측을 사람이 참고할 수는 있지만 완전한 복제나 미래 수익을 보장하지 않습니다.

자료를 어떻게 이용하나요?

과거 거래·성과 검증과 사람이 읽는 참고에 한정합니다. 자동매매 알고리즘 학습·무단 봇 제작·배포·판매에 사용하지 않습니다. 계정 연결·파일 업로드·시장 데이터 조회·주문 전송 기능이나 추적 도구도 없습니다. 외부 참고 링크에는 해당 서비스의 정책이 적용됩니다.
