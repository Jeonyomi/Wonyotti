# 공개 거래내역 검증 안내 화면 계획

**문서 버전: v1.1.0 · 수동 현황 스냅샷: 2026-09-22**

이 문서는 현재 공개 목적과 화면의 확인 기준을 정리합니다. 구현 완료·검사 통과·외부 작업 승인 기록이 아닙니다. 종전 문서의 보존을 이유로 현재 목적에 맞지 않는 내용을 공개 부록이나 복사본으로 남기지 않습니다.

## 목적과 현재 상태

목적은 `historical_review`입니다. 과거 거래·회계 검증의 범위와 한계를 설명하고 사람이 기록을 읽을 때 참고할 관찰을 제공합니다. 자동매매 알고리즘 학습·무단 봇 제작·배포·판매에 사용하지 않습니다.

- 거래·지갑 원본: `dataset_status: NOT_ACQUIRED`.
- 원본 열·단위·식별자: `schema_status: UNVERIFIED`.
- 공개 체결 대조·장부 대사: `verification_status: NOT_RUN`.
- 원문 게시 URL·게시 시각: 미확인.
- 실제 데이터 감사·장부 대사·성과 보고서: 없음.

공개자 공지는 사용자가 전달한 요약입니다. 원문을 독립 인증했거나 법률적 판단을 내렸다는 뜻이 아닙니다. 요약의 취지는 과거 거래·성과 확인과 사람의 참고이며, 체결만으로 무거래 판단·취소 주문·이유를 복원할 수 없다는 한계와 닉네임을 내세운 봇을 구매·신뢰하지 말라는 경고를 포함합니다.

## 화면 범위

HTML이 핵심 설명을 담고 CSS·JavaScript가 반응형 화면과 브라우저 안의 조작을 보완합니다. 런타임 외부 패키지, 자료 수집·업로드·계정 연결·거래 실행·방문자 추적을 추가하지 않습니다.

1. 첫 화면에서 목적, 독립 비공식·비제휴·비보증, 투자 조언 아님, 자료 미확보를 알립니다.
2. 출처·권리·파일 목록·해시, 공개 체결 대조, 회계 대사, 관측 가능한 포지션 설명, 과거 성과·위험 정의를 구분합니다.
3. 공개 체결 일치와 계정 소유·전체 내역의 완전성을 분리합니다. 숨은 판단 이유를 관측 사실로 표시하지 않습니다.
4. 참고 출처는 BitMEX execution·trade·wallet·archive, Excel, DuckDB로 구성하고 각 링크의 한계를 표시합니다.
5. 출처 검색·분류·결과 수·빈 결과·초기화, 공유 요약 복사와 대체 경로, 인쇄를 제공합니다.
6. JavaScript 없이도 핵심 내용에 접근할 수 있게 합니다. 임의 성과 차트·수익 수치·진행률을 넣지 않습니다.

## 문서 일관성

- README는 간결한 과거 검증 노트이며 실제 구현된 분석 기능처럼 쓰지 않습니다.
- 정보 원칙은 사용자 제공 요약의 출처 한계, 권한·개인정보, 오류 제보·정정을 설명합니다.
- 공개 체크리스트는 실제 확인 전 미완료로 둡니다. 날짜·상태·목적·참고 출처를 화면·공유·인쇄와 맞춥니다.
- 원본 자료·주소·계정 식별자·비밀정보를 저장소나 공개 이슈에 넣지 않습니다.
- 외부 기술 문서는 원본 확보·계정 소유·성과 인증의 근거가 아닙니다.

## 검증 기준

Node.js 24 이상에서 다음 명령을 사용합니다. 이는 실행 안내이며 결과 기록이 아닙니다.

```bash
npm ci
npx playwright install chromium
npm test
npm run check
npm run build
npm run test:browser
npm run preview
```

브라우저 검사는 빌드된 `dist/`를 대상으로 합니다. 목적·상태·출처, 검색·초기화·복사 대체·인쇄, 키보드·포커스·레이블·대비, JavaScript 없는 화면을 확인합니다. 320·390·768·1440px에서 넘침·겹침·잘림을 살피고 자동 접근성 검사와 수동 확인을 구분합니다.

검토 기록에는 실제 대상·명령·종료 코드·확인 시각·실패와 미실행 항목을 남깁니다. 화면 테스트는 거래·회계 검증을 대신하지 않습니다.

## 공개와 정정

명시적 검토 전 `noindex`를 유지합니다. 검색 제한은 접근 제어나 비밀 보호가 아닙니다. 정적 자산 요청과 호스팅 접속 로그 가능성, 외부 링크의 개인정보 정책을 안내합니다.

push·PR·배포·검색 색인 변경은 문서가 부여하는 권한이 아니며 실제 승인 범위를 별도로 확인합니다. 정정은 공개 근거 또는 재현 절차를 받아 확인 범위·수정 내용·수정일과 함께 기록합니다. 원본 자료 제출이나 제보 자체를 이용 허락 또는 당사자 인증으로 취급하지 않습니다.
