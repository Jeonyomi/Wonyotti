# 개발 및 공개 체크리스트

공개 대상은 정적 연구 안내 화면과 문서입니다. 실제 거래 분석 서비스나 매매 봇을 공개하는 절차가 아닙니다. 이 문서는 공개 승인, 테스트 통과, push 또는 배포 완료 기록을 대신하지 않습니다.

[README](../README.md) · [정보·출처·개인정보 원칙](INFORMATION-POLICY.md)

## 기여 범위

- 안내 문구, 정보 구조, 접근성, 반응형 화면, 출처 탐색, 공유 요약·인쇄 기능과 이를 확인하는 테스트를 개선합니다.
- 브라우저 실행 코드는 HTML·CSS·JavaScript로 유지합니다. 개발·검사용 의존성과 런타임 의존성을 구분하고, 추적 도구·계정·업로드·외부 데이터 조회 기능을 임의로 추가하지 않습니다.
- 연구 방법론, 후보 모듈, CLI 예시는 실제 구현 및 실행 결과와 분리합니다. 원본 미확보 상태에서 데이터 감사·대사·백테스트 보고서를 생성한 것처럼 표시하지 않습니다.
- README의 YAML 연구 상태와 상세 가이드는 근거 없이 바꾸지 않습니다. 실제 연구 상태가 달라졌을 때만 근거, 확인 범위, 수동 기준일을 함께 갱신합니다. 화면 수정일을 연구 검증일로 쓰지 않습니다.
- 원본 거래·지갑 파일, 지갑 주소, 식별 가능한 계정 정보, API 키·개인키·시드 문구를 Git, 테스트 자료, 화면 캡처, 로그 또는 공개 이슈에 넣지 않습니다. 필요한 테스트는 실제 자료와 명확히 구분한 합성 데이터로 작성합니다.

## 로컬 개발과 검증

개발·검증에는 Node.js 24 이상이 필요합니다. `package.json`과 `package-lock.json`에 맞춰 개발용 jsdom·Playwright·axe를 설치하며, 브라우저 테스트에는 Playwright Chromium도 필요합니다.

```bash
npm ci
npx playwright install chromium
npm test
npm run check
npm run build
npm run test:browser
npm run preview
```

| 명령 | 용도 |
|---|---|
| `npm ci` | 잠금 파일 기준 개발 의존성 설치 |
| `npx playwright install chromium` | 브라우저 검증용 Chromium 설치 |
| `npm test` | Node 기반 테스트 실행 |
| `npm run check` | 저장소 정적 검사 실행 |
| `npm run build` | `dist/` 정적 배포 산출물 생성 |
| `npm run test:browser` | Playwright·axe 기반 브라우저 검사 실행 |
| `npm run preview` | 로컬 미리보기 서버 실행; 접속 주소는 터미널 출력 확인 |

의존성과 브라우저 설치에는 네트워크가 필요할 수 있습니다. 이는 사이트 방문 시 외부 데이터 API를 호출한다는 뜻이 아닙니다. `npm run test:browser`는 빌드된 `dist/`와 전용 로컬 서버를 사용하므로 먼저 빌드하고, 같은 포트의 미리보기 서버는 종료합니다. 검증 도구가 설치되지 않았거나 실행에 실패했다면 그 검사는 미실행 또는 실패로 기록합니다. 다른 검사의 통과로 대체하지 않습니다.

아래 체크리스트는 미완료 상태로 제공됩니다. 실제 릴리스 검토 기록에 대상 커밋 또는 작업 트리, 명령, 종료 코드, 실행 환경, 확인 시각과 남은 실패 항목을 남긴 뒤 해당 항목을 완료 처리합니다. 화면·문서·설정을 수정했다면 최종 상태에서 다시 확인합니다.

## 공개 전 체크리스트

### 정보와 권리

- [ ] README YAML, 화면 상태, 공유 요약, 인쇄 내용에 같은 연구 상태가 표시된다. 현재 기준은 `NOT_ACQUIRED` / `UNVERIFIED` / `NOT_RUN` / `NOT_RUN`, 실거래 `false`다.
- [ ] 기준일 `2026-09-22`를 수동 연구 현황으로 설명한다. 최신 조회·원문 게시일·배포 시각으로 표시하지 않는다.
- [ ] 원문 URL·게시 시각 미확인과 원본 파일 미확보를 첫 화면에서 알 수 있다.
- [ ] 사용자 제공 공지의 숫자는 미검증 주장으로 귀속한다. 산술 계산을 수익률 인증으로 표현하지 않고, 임의의 KPI·진행률·성과 차트를 추가하지 않는다.
- [ ] API·기술 문서·논문의 확인 범위를 적는다. 링크의 존재를 원본 확보, 계정 소유, 전체 거래의 진위·완전성 증거로 사용하지 않는다.
- [ ] 상세 가이드 §1.2·S1의 시점 의존적인 운영 공지와 아래 [정보 점검 기록](INFORMATION-POLICY.md#information-audit)을 확인한다. 2026-09-22 공식 지원 API 재확인은 종료 시각·종료 후 계정 접근 범위에 한정되며, 이후 변경이나 공개 아카이브 지속 제공을 보장하지 않는다.
- [ ] 독립 비공식 프로젝트, 비제휴·비보증, 교육·연구 목적, 투자 조언 아님을 명시한다.
- [ ] 원본에 접근할 수 있다는 사실과 재배포·상업적 이용·AI 학습·외부 업로드 권한을 구분한다. 권한이 불명확하면 해당 이용을 보류한다.
- [ ] 소스와 빌드 산출물에 원본 데이터·지갑 주소·비밀정보가 없고, 공개 이슈에도 이를 제출하도록 요구하지 않는다.

### 기능과 접근성

- [ ] `npm test`, `npm run check`, `npm run build`, `npm run test:browser`를 최종 상태에서 실행하고 결과를 기록한다.
- [ ] 출처 검색·분류·결과 수·빈 결과·초기화가 일관되게 작동한다. 링크가 없거나 출처 확인이 제한적인 상태를 숨기지 않는다.
- [ ] 공유 요약은 연구 상태와 한계를 포함한다. 클립보드 사용 불가 시 복사 가능한 대체 경로가 있으며, 인쇄본에서도 주의 문구가 유지된다.
- [ ] JavaScript 없이도 핵심 설명·상태·출처에 접근할 수 있다.
- [ ] 키보드 탐색, 본문 바로가기, 포커스 표시, 폼 레이블, 상태 알림, 색 대비와 동작 줄이기 설정을 확인한다. 자동 접근성 검사만으로 전체 접근성을 보증하지 않는다.
- [ ] 320·390·768·1440px 화면과 인쇄에서 가로 넘침·겹침·잘림을 확인한다.
- [ ] 내부 이동, 문서 링크, 외부 링크, 메타데이터와 공유 이미지를 확인한다. 외부 링크 오류는 원본 자료의 부재나 폐쇄로 단정하지 않는다.

### 개인정보와 배포 경계

- [ ] 앱에 분석 추적, 계정, 업로드, 쿠키·로컬 저장, 외부 데이터 API 호출이 추가되지 않았다. 도입하려면 먼저 별도 검토와 고지 변경을 거친다.
- [ ] 외부 링크에는 해당 사이트의 정책이 적용되며, 호스팅 제공자는 접속 로그를 보관할 수 있다는 안내가 있다. 로그 보관 기간은 확인 없이 단정하지 않는다.
- [ ] HTML robots 메타, `robots.txt`, 호스팅의 `X-Robots-Tag`를 확인한다. 명시적 공개·색인 검토 전에는 `noindex` 등 현재 제한을 유지한다.
- [ ] 배포 산출물·보안 헤더·오류 화면을 확인한다. 로컬 미리보기 성공을 실제 호스팅 환경 검증으로 대신하지 않는다.
- [ ] 승인권자가 대상 브랜치·산출물·배포 위치·공개 범위를 검토했다. push·PR·배포는 각 작업의 명시적 허가 후 진행하고, 검색 색인 허용도 따로 결정한다.

`noindex`와 `robots.txt`는 접근 제어나 비밀 보호 수단이 아닙니다. 주소를 아는 사람은 페이지에 접근할 수 있고, 검색 로봇이 지시를 따르지 않을 수도 있습니다. 공개해서는 안 되는 자료를 넣지 않는 것이 우선입니다.

## 공개 후 변경과 정정

- 출처 오류·설명 부족·접근성 문제는 [GitHub Issues](https://github.com/Jeonyomi/Wonyotti/issues)로 제보받습니다. 페이지와 문구, 재현 절차 또는 공개 근거 링크만 남기고, 원본 파일·지갑 주소·계정 정보·비밀정보를 첨부하지 않습니다.
- 정정 시 수정 전 주장, 근거, 변경 내용, 확인일을 검토 기록에 남깁니다. 삭제나 링크 교체만으로 과거 검증이 유효했던 것처럼 만들지 않습니다.
- 실제 자료 확보, 추적 도구 도입, 계정·업로드 추가, 실거래 연동은 이 정적 사이트의 단순 개선 범위를 벗어납니다. 별도 권한·개인정보·보안·정보 품질 검토가 필요합니다.
