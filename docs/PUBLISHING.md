# 개발 및 공개 체크리스트

공개 대상은 과거 거래·회계 검증 기준과 사람이 참고할 관찰을 설명하는 정적 화면과 문서입니다. 이 체크리스트는 공개 승인, 검사 통과, push 또는 배포 완료 기록이 아닙니다.

[검증 노트](../README.md) · [정보·출처·개인정보 원칙](INFORMATION-POLICY.md)

## 기여 범위

- 안내 문구·정보 구조·접근성·반응형 화면·출처 탐색·공유 요약·인쇄와 화면 검사를 개선합니다.
- 브라우저 실행 코드는 HTML·CSS·JavaScript입니다. 자료 수집·계정 연결·거래 실행 기능은 제공하지 않습니다.
- 목적은 `historical_review`입니다. 자동매매 알고리즘 학습·무단 봇 제작·배포·판매에 사용하지 않습니다.
- README 상태는 증거가 달라졌을 때만 확인 범위와 수동 기준일을 함께 갱신합니다. 화면 수정일을 거래 검증일로 쓰지 않습니다.
- 원본 거래·지갑 파일·지갑 주소·계정 정보·비밀정보를 Git·테스트·화면 캡처·로그·공개 이슈에 넣지 않습니다.
- 과거의 부적절한 설명을 보존한다는 이유로 공개 부록이나 복사본을 만들지 않습니다.

## 로컬 개발과 검증

Node.js 24 이상을 사용합니다. 잠금 파일에 맞춰 개발용 jsdom·Playwright·axe를 설치합니다. 브라우저 검사에는 Playwright Chromium이 필요합니다.

```bash
npm ci
npx playwright install chromium
npm test
npm run check
npm run build
npm run test:browser
npm run preview
```

| 명령 | 용도 |
|---|---|
| `npm ci` | 잠금 파일 기준 의존성 설치 |
| `npx playwright install chromium` | 검사용 Chromium 설치 |
| `npm test` | Node 기반 검사 |
| `npm run check` | 정적 검사 |
| `npm run build` | `dist/` 배포 산출물 생성 |
| `npm run test:browser` | Playwright·axe 브라우저 검사 |
| `npm run preview` | 로컬 미리보기; 주소는 터미널 출력 확인 |

의존성과 브라우저 설치에는 네트워크가 필요할 수 있습니다. 브라우저 검사는 빌드된 `dist/`와 전용 로컬 서버를 사용하므로 먼저 빌드하고, 같은 포트의 미리보기 서버는 종료합니다. 도구가 없거나 실행에 실패했다면 미실행 또는 실패로 기록합니다.

검토 기록에는 대상 커밋 또는 작업 트리, 명령, 종료 코드, 환경, 실제 확인 시각, 남은 실패 항목을 남깁니다. 아래 항목은 완료 사실이 아니라 공개 전 확인할 목록입니다.

## 정보·목적·권리

- [ ] README·화면·공유 요약·인쇄본의 목적과 상태가 일치한다: `historical_review`, `NOT_ACQUIRED`, `UNVERIFIED`, `NOT_RUN`.
- [ ] v1.1.0의 기준일 `2026-09-22`를 수동 현황 스냅샷으로 설명한다. 실시간 조회일·원문 게시일로 쓰지 않는다.
- [ ] 원문 URL·게시 시각 미확인, 원본 파일 미확보, 실제 검증 미실행을 명시한다.
- [ ] 공개자 공지는 사용자 제공 요약임을 밝힌다. 독립 인증된 원문·직접 인용·법률적 판단으로 표시하지 않는다.
- [ ] 과거 거래·성과 확인과 사람의 참고라는 목적, 허락 없는 이용 금지, 닉네임을 내세운 봇에 대한 경고가 유지된다.
- [ ] 체결만으로 무거래 판단·취소 주문·매매 이유를 복원할 수 없다는 한계를 설명한다.
- [ ] 공지의 수치와 실제 확인된 결과를 구분하고 임의 KPI·진행률·성과 차트를 넣지 않는다.
- [ ] 공개 체결 일치와 계정 소유·전체 내역의 완전성을 구분한다.
- [ ] 손익·수수료·펀딩의 중복 합산, 입출금·미실현손익·단위·기간의 누락을 경계한다.
- [ ] 출처는 BitMEX execution·trade·wallet·archive, Excel, DuckDB의 참고 범위를 설명한다. 링크를 원본 확보나 성과 인증 근거로 쓰지 않는다.
- [ ] 독립 비공식·비제휴·비보증·투자 조언 아님을 명시한다.
- [ ] 접근 가능성과 이용 권한을 구분하며 불명확한 이용은 보류한다.
- [ ] 원본 데이터·주소·식별자·비밀정보가 소스와 배포 산출물에 없다.

## 화면과 접근성

- [ ] 최종 상태에서 `npm test`, `npm run check`, `npm run build`, `npm run test:browser`를 실행하고 결과를 기록한다.
- [ ] 출처 검색·분류·결과 수·빈 결과·초기화가 일관되게 작동한다.
- [ ] 공유 요약·인쇄본에 목적과 미확인 상태가 유지되며 복사 실패 시 대체 경로가 있다.
- [ ] JavaScript 없이도 핵심 설명·상태·출처를 읽을 수 있다.
- [ ] 키보드 탐색·본문 바로가기·포커스·레이블·상태 알림·색 대비·동작 줄이기를 확인한다.
- [ ] 320·390·768·1440px 및 인쇄에서 넘침·겹침·잘림을 확인한다.
- [ ] 내부 문서·외부 링크·메타데이터·공유 이미지가 현재 목적과 일치한다.
- [ ] 검사 통과를 거래 진위·성과 또는 전체 접근성의 보증으로 표현하지 않는다.

## 개인정보와 배포

- [ ] 추적·광고·계정·업로드·쿠키·로컬 저장·외부 데이터 API 호출이 추가되지 않았다.
- [ ] 정적 자산 요청, 호스팅 로그 가능성, 클립보드·인쇄 결과, 외부 서비스 정책을 설명한다.
- [ ] HTML robots 메타·`robots.txt`·호스팅의 `X-Robots-Tag`를 확인하고 명시적 색인 검토 전 `noindex`를 유지한다.
- [ ] 배포 산출물·보안 헤더·오류 화면을 확인한다. 로컬 미리보기 성공을 호스팅 검증으로 대신하지 않는다.
- [ ] 대상 브랜치·산출물·배포 위치·공개 범위를 확인한다. push·PR·배포·검색 색인은 각각 실제 허가 범위에 따라 처리한다.

`noindex`와 `robots.txt`는 접근 제어나 비밀 보호 수단이 아닙니다. 공개해서는 안 되는 자료를 넣지 않는 것이 우선입니다.
