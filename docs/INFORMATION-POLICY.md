# 정보·출처·개인정보 원칙

이 사이트는 과거 공개 거래·성과의 검증 기준과 사람이 참고할 관찰을 설명하는 독립 비공식 프로젝트입니다. 워뇨띠·BitMEX와 제휴하거나 승인·보증을 받은 공식 서비스가 아닙니다. 투자 조언, 매매 추천, 성과 보장, 계정 소유 인증 또는 법률적 인증을 제공하지 않습니다.

[검증 노트](../README.md) · [개발·공개 체크리스트](PUBLISHING.md)

## 공개 목적과 공지의 출처

사용자가 전달한 공개자 공지 요약에 따르면, 공개 목적은 과거 거래·성과 확인과 사람이 참고할 관찰이며 알고리즘 학습용 제공이 아닙니다. 허락 없는 봇 제작·배포·판매를 하지 말고, 닉네임을 내세운 봇을 구매하거나 신뢰하지 말라는 취지가 포함돼 있습니다. 체결 기록만으로 거래하지 않은 판단·취소 주문·매매 이유까지 알 수 없다는 한계도 함께 전달됐습니다.

**원문 URL과 게시 시각은 미확인입니다.** 이 요약은 사용자 제공 내용이지 독립적으로 인증한 공지나 당사자의 직접 인용이 아닙니다. 이를 허락의 증명 또는 법률적 판단으로 사용하지 않습니다.

이 프로젝트는 **자동매매 알고리즘 학습·무단 봇 제작·배포·판매에 사용하지 않습니다.** 자료 이용은 과거 거래·회계 검증과 사람에게 설명할 관찰로 한정합니다.

## 현재 확인 범위

**v1.1.0 · 수동 현황 스냅샷 2026-09-22.** 기준일은 원문 게시일·실시간 조회일·배포일이 아닙니다.

| 항목 | 상태와 의미 |
|---|---|
| 목적 | `purpose: historical_review` |
| 거래·지갑 원본 | `dataset_status: NOT_ACQUIRED` — 파일·해시 미확보 |
| 원본 열·단위·식별자 | `schema_status: UNVERIFIED` — 실제 구조 미확인 |
| 공개 체결 대조·회계 검증 | `verification_status: NOT_RUN` — 실제 결과 없음 |
| 원문 출처 | `original_post_url`·`original_post_published_at`은 `null` |

현재 구현은 정적 안내와 브라우저 안의 출처 탐색·공유 요약·인쇄입니다. 자료 수집·업로드·계정 연결·거래 실행 기능과 실제 데이터 감사·장부 대사·성과 보고서는 없습니다. 문서의 확인 기준을 구현 완료나 분석 결과로 표시하지 않습니다.

## 주장과 근거를 표시하는 법

- 사용자 제공 공지의 수치·기간·규모는 미검증 주장으로 귀속합니다. 숫자의 산술 일치와 원본 정확성·완전성·성과 인증은 구분합니다.
- 수치를 제시할 때는 단위·기간·분모·계산 정의·원본 위치·제외 범위를 함께 남깁니다. 근거가 없으면 미확인 또는 미실행으로 표시합니다.
- 공개 체결 일치, 공개본 내부 누락 여부, 계정 소유, 전체 계정·기간의 완전성을 하나의 검증 완료 표시로 합치지 않습니다.
- 관측한 포지션 수량·보유 시간·손익 분포와 실제 판단 이유를 구분합니다. 취소·미체결·무거래 판단은 기록 없이 복원하지 않습니다.
- 수수료·펀딩·실현손익의 중복 합산을 점검하고, 미설명 잔액 차이를 감추지 않습니다. 미실현손익·입출금·담보 가격 효과 없이 위험과 수익률을 확정하지 않습니다.
- API·도구 문서는 일반 사양의 참고자료입니다. 링크만으로 원본 확보, 과거 파일 접근 성공, 신원·성과·완전성을 입증하지 않습니다.
- 자료명·주소·지원하는 주장·실제 읽은 범위·확인일·미확인 사항을 기록합니다. 확인하지 않은 날짜나 출처를 만들지 않습니다.
- 접근 실패는 DNS·인증·접근 제한·서버 오류·자료 없음으로 구분합니다. 오류만으로 자료 폐쇄나 부재를 단정하지 않습니다.
- 화면 테스트와 빌드 통과는 문서에 적힌 거래·성과를 검증하지 않습니다. 명령 안내와 실제 실행 기록을 구분합니다.

## 이용 권한과 원본 보호

공개 접근 가능성은 재배포·상업적 이용·외부 서비스 업로드 권한이 아닙니다. 자료별 약관·라이선스·허락 범위와 개인정보 위험을 별도로 확인하고 불명확한 이용은 보류합니다. 프로젝트의 문서나 링크가 원본 자료의 권리를 부여하지 않습니다.

원본 거래·지갑 파일, 지갑 주소, 계정 식별자, API 키, 개인키, 시드 문구를 Git·공개 이슈·스크린샷·테스트·로그에 올리지 않습니다. 자료를 다룰 권한이 확인돼도 저장소 밖의 접근 제한 보관과 최소 공개를 원칙으로 합니다. 삭제된 식별자를 복구하거나 신원을 역추적하지 않습니다.

## 방문자 개인정보와 외부 서비스

현재 앱에는 분석 추적·광고·계정·로그인·파일 업로드·쿠키 또는 로컬 저장소를 이용한 방문자 정보 저장 기능이 없습니다. 출처 검색 등 화면 조작은 브라우저 안에서 처리하며 검색어를 외부 데이터 API로 보내지 않습니다. 페이지와 정적 자산 요청까지 없다는 뜻은 아닙니다.

공유 요약 복사와 인쇄는 사용자의 요청으로 실행됩니다. 클립보드·인쇄·PDF 결과는 사용자의 기기나 선택한 위치에 남을 수 있으며, 사이트의 계정이나 서버에 저장하는 기능은 없습니다.

호스팅 제공자는 페이지 제공·보안 운영 과정에서 IP 주소·요청 시각 등의 접속 로그를 보관할 수 있습니다. 실제 수집 범위와 보관 기간은 별도 확인 대상입니다. “아무 정보도 수집되지 않는다”거나 “로그가 남지 않는다”고 보장하지 않습니다.

외부 출처와 GitHub를 열면 해당 서비스의 개인정보·쿠키 정책이 적용됩니다. 기능과 개인정보 처리 범위가 달라지면 구현 전에 정책과 권한을 다시 검토합니다. 명시적 색인 검토 전 `noindex`를 유지하되 이를 접근 제어나 비밀 보호 수단으로 설명하지 않습니다.

## 오류 제보와 정정

출처 오류, 날짜·단위·설명 문제, 과도한 주장 또는 접근성 문제는 [GitHub Issues](https://github.com/Jeonyomi/Wonyotti/issues)로 제보해 주세요. 문제가 있는 페이지·문구, 제안 수정, 공개 근거 또는 재현 절차를 적습니다. 원본 거래·지갑 파일, 주소, 개인·계정 정보, 비밀정보는 첨부하지 마세요.

정정은 근거 확인 후 반영하고 확인 범위·수정 내용·수정일을 기록합니다. 철회한 부적절한 내용을 공개 부록으로 재게시하지 않습니다. 정정 요청이나 자료 제공 자체를 당사자 인증·자료 이용 허락·검증 완료로 간주하지 않습니다.
