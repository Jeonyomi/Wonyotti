# 정보·출처·개인정보 원칙

이 사이트는 워뇨띠 공개 거래내역에 관한 주장과 이를 검증할 방법을 구분해 설명하는 독립 비공식 연구 프로젝트입니다. 워뇨띠·BitMEX와 제휴하거나 이들의 승인·보증을 받은 공식 서비스가 아닙니다. 교육·연구 목적이며 투자 조언, 매매 추천, 수익 보장 또는 계정 소유 인증을 제공하지 않습니다.

## 현재 확인 범위

연구 가이드의 기준일은 **2026-09-22**입니다. 수동으로 기록한 연구 현황이며, 실시간 데이터 조회 시각·원문 게시일·사이트 배포일이 아닙니다. 이번 정비에서는 아래에 명시한 공식 지원 공지의 제한된 범위를 재확인했습니다. 이는 원본 거래의 독립 검증이나 출처 전체의 최신성 인증이 아닙니다.

| 항목 | 상태와 의미 |
|---|---|
| 거래·지갑 원본 | `dataset_status: NOT_ACQUIRED` — 파일과 해시를 확보하지 못함 |
| 원본 열·단위·식별자 | `schema_status: UNVERIFIED` — 기술 문서의 일반 스키마와 원본 구조는 별개 |
| 공개 체결 대조·장부 대사 | `verification_status: NOT_RUN` — 실제 대조 결과 없음 |
| 전략 백테스트 | `backtest_status: NOT_RUN` — 성과·위험 지표 없음 |
| 실거래 | `live_trading_enabled: false` — 자금 운용이나 거래 실행을 제공하지 않음 |
| 공지의 출처 | 사용자 제공 내용이며, `original_post_url`·`original_post_published_at`은 `null` |

`null`, `NOT_RUN`, 대기 또는 차단 상태는 성공이나 검증 완료를 뜻하지 않습니다. 현재 구현 범위는 연구 안내 화면과 문서입니다. 수집기, 정규화, 원장 대사, 행동 복원, 후보 전략, 학습, 백테스트, 봇 통합, Shadow·Canary는 연구 가이드의 제안 절차입니다. 화면에 절차나 후보 모듈이 있어도 해당 기능이 구현·실행됐다는 뜻은 아닙니다.

실제 자료에 근거한 `data_audit_report.md`, `ledger_reconciliation_report.md`와 성과 보고서는 아직 없습니다. 보고서 형식이나 테스트용 합성 자료가 있어도 실제 연구 결과로 승격하지 않습니다.

## 주장과 근거를 표시하는 법

- 사용자 제공 공지의 수치·기간·파일 규모는 공지의 주장으로 귀속하고 미확인 범위를 함께 씁니다. 프로젝트가 독립 확인한 성과로 표시하지 않습니다.
- 주어진 숫자의 산술 일치와 원본의 정확성, 수익률 정의, 완전성은 서로 다른 문제입니다. 산술이 맞아도 성과를 인증한 것은 아닙니다.
- 숫자를 공개할 때는 분모·단위·기간·계산 정의·근거를 함께 남깁니다. 근거가 없으면 미확인 또는 미실행으로 표시하며, KPI·승률·Sharpe·수익 곡선·진행률을 임의로 만들지 않습니다.
- 공식 API·도구 문서는 일반 사양과 구현 방법의 근거입니다. 원본 파일을 확보했다거나 특정인의 거래·계정 소유를 입증하지 않습니다. 공개 체결 일치만으로 전체 거래의 완전성이나 신원을 인증하지 않습니다.
- 논문 초록·서지 확인, 논문 전체 검토, 수식·코드 검증, 실제 실험을 구분합니다. 논문을 연결한 것만으로 통계 검증을 마친 것으로 표시하지 않습니다.
- 출처에는 주소·자료명·지원하는 주장·실제 읽은 범위·확인일·미확인 사항을 남깁니다. 문서 개정일, 연구 기준일, 자료 조회일, 원문 게시일을 섞지 않습니다. 확인하지 않은 날짜는 만들지 않습니다.
- API나 아카이브 링크의 존재는 과거 파일 다운로드 성공이나 전 기간 커버리지의 증거가 아닙니다. DNS·인증·접근 제한·서버 오류와 자료 없음도 구분합니다.
- UI 테스트와 빌드의 통과는 연구 결과의 진위 검증이 아닙니다. 명령 안내나 체크리스트만으로 테스트·배포가 성공했다고 주장하지 않습니다.

## 이용 권한과 원본 보호

공개 접근 가능하다는 사실은 재배포·상업적 이용·AI 학습·외부 서비스 업로드 권한을 뜻하지 않습니다. 사이트의 참고 링크나 이 프로젝트 문서도 원본 자료에 대한 권리를 부여하지 않습니다. 이용하려는 자료별 약관·라이선스·허락 범위와 개인정보 위험을 별도로 확인하고, 불명확한 이용은 보류합니다.

원본 거래·지갑 데이터, 지갑 주소, 계정 식별자, API 키, 개인키, 시드 문구를 Git 저장소·공개 이슈·스크린샷·테스트·로그에 올리지 않습니다. 가이드에 원본 보존 디렉터리가 제안돼 있어도 Git 커밋을 허용한다는 뜻은 아닙니다. 향후 적법한 자료 취급이 필요하면 저장소 밖의 통제된 보관, 권한과 보존 범위 검토를 먼저 거칩니다. 제거된 주소나 신원을 역추적하지 않습니다.

## 방문자 개인정보와 외부 서비스

현재 자사 앱에는 분석 추적, 광고, 계정·로그인, 파일 업로드, 쿠키 또는 로컬 저장소를 이용한 방문자 정보 저장 기능이 없습니다. 출처 탐색 등 화면 조작은 브라우저 안에서 처리하며 외부 데이터 API로 검색어를 보내지 않습니다. 페이지와 정적 자산을 불러오는 통신까지 없다는 뜻은 아닙니다.

공유 요약 복사와 인쇄는 사용자의 요청으로 실행합니다. 복사한 내용은 운영체제의 클립보드에, 인쇄·PDF 저장 결과는 사용자가 정한 위치에 남을 수 있습니다. 이를 사이트의 계정이나 서버에 저장하는 기능은 없습니다.

호스팅 제공자는 페이지 제공·보안 운영 과정에서 IP 주소, 요청 시각 등 접속 로그를 보관할 수 있습니다. 제공자의 실제 수집 범위와 보관 기간은 별도 확인 대상이며, 이 프로젝트는 “어떤 정보도 수집되지 않는다”거나 “로그가 남지 않는다”고 보장하지 않습니다.

외부 출처와 GitHub 링크를 열면 해당 서비스의 개인정보·쿠키 정책이 적용됩니다. 링크를 제공한다는 이유만으로 그 서비스의 정보 처리나 내용을 보증하지 않습니다. 분석 도구·계정·업로드·저장 기능을 추가하려면 구현에 앞서 범위와 정책을 다시 검토합니다.

## 오류 제보와 정정

출처 오류, 날짜·단위 문제, 과도한 주장 또는 접근성 문제는 [GitHub Issues](https://github.com/Jeonyomi/Wonyotti/issues)로 제보해 주세요. 문제가 있는 페이지·문구, 제안 수정, 공개 근거 링크 또는 재현 절차를 적습니다. 원본 거래·지갑 파일, 지갑 주소, 개인·계정 정보나 비밀정보는 첨부하지 마세요. 민감한 자료를 공개 이슈로 전달하도록 요청하지 않습니다.

정정은 근거 확인 후 반영하고, 주장·근거·확인 범위·수정일을 함께 기록합니다. 파일 제공이나 정정 요청 자체를 자료 이용 허락, 당사자 인증 또는 외부 사실의 검증 완료로 간주하지 않습니다.
